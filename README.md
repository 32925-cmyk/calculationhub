# calculationhub

A fast web app that provides multiple types of calculations in one place:

- Basic arithmetic (+, -, ×, ÷, power)
- Scientific operations (sqrt, square, sin, cos, tan, log10)
- Finance (simple interest)
- Health (BMI)
- Unit conversion (distance and temperature)

## Run locally

Open `/home/runner/work/calculationhub/calculationhub/index.html` in a browser.

Or run a local static server:

```bash
cd /home/runner/work/calculationhub/calculationhub
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
